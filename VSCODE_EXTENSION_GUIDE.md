## 🎯 **Возможности расширения**

### **Команды VS Code**
```bash
OHI-S ASSISTANT: Start Chat           # Открыть чат в WebView
OHI-S ASSISTANT: Start Docker Container  # Запустить контейнер
OHI-S ASSISTANT: Stop Docker Container   # Остановить контейнер
```

### **Настройки**
```json
{
  "openwebui.docker.enabled": true,
  "openwebui.docker.image": "ghcr.io/open-webui/open-webui:ollama",
  "openwebui.docker.port": 3000,
  "openwebui.webview.enabled": true
}
```

## 🚀 **Как использовать**

### **Быстрая установка**
1. Скачайте `open-webui-0.1.0.vsix`
2. VS Code → `Ctrl+Shift+P` → "Extensions: Install from VSIX..."
3. Выберите файл и перезапустите

### **Запуск**
1. `Ctrl+Shift+P` → "OHI-S ASSISTANT: Start Docker Container"
2. `Ctrl+Shift+P` → "OHI-S ASSISTANT: Start Chat"
3. Наслаждайтесь AI чатом прямо в VS Code! 🎉

```bash
cd open-webui-vscode
npm install

```

```bash
npm install -g vsce
vsce package
```
